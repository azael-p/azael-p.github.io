# Portfolio — Azael Pignanessi

Portfolio personal de Azael Pignanessi, Full-Stack Developer Uruguayo.

🔗 **Live:** https://azael-p.github.io

---

## Stack

HTML5 · CSS3 · JavaScript vanilla · AOS · Google Fonts

---

## Features

- Dark / Light mode (guardado en localStorage)
- Traducciones ES / EN (guardado en localStorage)
- Custom cursor en desktop (dot + ring con lag)
- Scroll progress bar
- Hero staggered animation (5 elementos con delays escalonados)
- Rotating border avatar
- 3D card tilt en project cards (hover)
- Skills marquee animado bidireccional
- Stat cards en sección "Sobre mí"
- Section number labels decorativos
- Responsive (mobile-first)
- Accesibilidad: focus styles visuales
- Soporte `prefers-reduced-motion`
- Smooth scroll
- Scrollbar custom

---

## Secciones

1. **Hero** — Presentación con avatar animado
2. **Sobre mí** — Bio + stat cards (3 proyectos, Mercado Libre, Universidad)
3. **Proyectos** — 3 cards con tilt 3D (reps.io, Galería Demo, Estudio Notarial)
4. **Skills** — Marquee infinito con tecnologías
5. **Certificaciones** — Udemy certificates
6. **Contacto** — Links + CV descargable
